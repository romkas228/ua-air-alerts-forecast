# CLAUDE.md — ua-air-alerts-forecast

## Проєкт
Mini pet-project на Python: аналіз часових рядів і прогнозування повітряних тривог в Україні.
AI (Claude Code) — основний інженерний інструмент проєкту, а не прикраса.

## Вимоги ТЗ (обов'язкові, не порушувати)
1. **Найсвіжіші дані.** Працюємо з найактуальнішими доступними даними тривог.
2. **Оцінка на останньому періоді.** Test/holdout = найсвіжіший відрізок часу (не випадковий split).
3. **Жодного data leakage.** Ніщо, на чому модель навчається або що подається на вхід,
   не може походити з часу *після* моменту прогнозу (`forecast_time`):
   - тільки time-based split / rolling-origin (walk-forward) валідація;
   - фічі рахуються лише з даних із `timestamp < forecast_time`
     (лаги, rolling-вікна — з явним зсувом; жодних `center=True`, bfill, глобальної нормалізації по всьому ряду);
   - скейлери/енкодери фітяться тільки на train-частині кожного фолда;
   - для тривог, які ще тривають у `forecast_time`, не використовуємо їх майбутній час завершення.
4. **Опційно: текст/медіа** (новини, офіційні заяви, публічні Telegram-канали) — за тим самим правилом:
   використовуємо лише контент із `published_at < forecast_time`. Зберігаємо `published_at` для кожного запису.
5. Leakage-правила покриваємо **автотестами**.

## Правила співпраці
- Ми йдемо поетапно: (1) репозиторій → (2) стек і архітектура → (3) покрокова реалізація.
- **Питай якомога частіше** — про будь-які неочевидні рішення (джерела даних, горизонт прогнозу,
  гранулярність, метрики, стек), перш ніж реалізовувати. Краще запитати, ніж переробляти.
- Спілкування з користувачем — українською. Код, коміти, docstrings — англійською.
- Важливі рішення та відповіді користувача фіксуй у розділі «Журнал рішень» нижче.

## Команди
- `uv sync` — встановити залежності; `uv run uaalerts --help` — CLI.
- Перевірки (те саме, що в CI): `uv run ruff check . && uv run ruff format --check . && uv run mypy src && uv run pytest -m "not network"`.
- macOS: LightGBM потребує `brew install libomp`.
- Дашборд: `uv run uaalerts update --retrain && uv run streamlit run app/dashboard.py`.
- Архітектура: `docs/ARCHITECTURE.md`. Конфіг прогнозу: `configs/default.yaml`.
